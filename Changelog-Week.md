# Changelog


## New mods

### GlobalList Atlas

- Description: Connects to the community&#x27;s global spreadsheet archive of fan-made rated maps. Browse and filter maps by editor, tags, rating and verification status, then download, install, and launch them directly from an in-game menu — including required editors and public mods.
- Integrations
  + Architect
  + ArchitectLegacy
  + DecorationMaster
- Tags
  + Utility

### HallownestWayfinder

- Description: An in-game route guide and navigation assistant with guided 112%, five-hour speedrun and save-completion routes, a progress checklist, and save-aware pathfinding.
- Tags
  + LLM-Assisted
  + Utility

### Input Display

- Description: Shows an input display in the bottom right corner. Compatible with both controller and mouse/keyboard.
- Dependencies
  + MagicUI
- Tags
  + Utility

### RadianceSkin

- Description: A mod that customizes Absolute Radiance with selectable skins, music, visual effects, backgrounds, and animations.
- Dependencies
  + Satchel
  + WavLib
- Tags
  + Cosmetic
