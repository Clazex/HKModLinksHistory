# Changelog


## New mods

### Charm Rebalanced

- Description: A mod that balances and reworks almost all charms! Click [View Readme] to see all the changes.
- Tags
  + Charm

### CharmRebalanced

- Description: Dummy mod. Install the dependency &quot;Charm Rebalanced&quot; directly.
- Dependencies
  + Charm Rebalanced

### Hollow Knight ACTS

- Description: A mod which adds Skongs ACT system to hk. Act positions based of Singbuzzordenethcut video on yt.
- Dependencies
  + SFCore
  + WavLib
- Tags
  + Gameplay

### Lego Power Bricks

- Description: Adds various of the iconic Red Lego Power Bricks to Hollow Knight, in the form of free charms. Currently requires Debug to give yourself the charms.
- Dependencies
  + MagicUI
  + SFCore
  + Satchel
- Tags
  + Charm

### LieButton

- Description: A simple mod for Hollow Knight. Press a certain customizable key to lie down or get up, like a switch.
- Dependencies
  + Satchel
- Tags
  + Cosmetic

### RngSync

- Description: A Hollow Knight mod that makes a lot of RNG deterministic

### WavLib

- Description: A library to read and write WAV files.
- Tags
  + Library
