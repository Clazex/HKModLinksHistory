# Changelog


## New mods

### Inputs Recheck

- Description: Rechecks for the held buttons on any Knight state change, so the action is triggered even if the button was pushed down before it was available, if the button is still held down. Based on Input Buffers mod by Phenomenol, but with completely different logic.
- Dependencies
  + Vasi
- Tags
  + Gameplay

### MoreStags

- Description: A Randomizer connection which adds new stag stations
- Dependencies

  + ItemChanger
  + MenuChanger
  + Randomizer 4
  + RandomizerCore
  + RandomizerCore.Json
  + Satchel
- Integrations
  + CondensedSpoilerLogger
  + DebugMod
  + RandoSettingsManager

### Shared Health

- Description: A HKMP addon to synchronize damage and healing across teams.
- Dependencies
  + HKMP
  + HKMirror

- Tags

### StartingNotches

- Description: Lets you play with an adjustable amount of extra Charm Notches, default starts at 2.
- Dependencies
  + Satchel
- Tags
  + Gameplay
