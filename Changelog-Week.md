# Changelog


## New mods

### HKMP.Rounds

- Description: An HKMP addon that adds a round-based system, automatic round starts, and PvP win statistics.
- Dependencies
  + HKMP
- Tags
  + Gameplay
  + Utility

### HollowKnightTAS

- Description: A TAS toolkit for Hollow Knight with a visual Studio editor, frame-by-frame input editing, recording and replay, timeline branching, MP4 export, and local control for AI agents and scripts. Windows only.
- Tags
  + Utility

### VocesDelVacio

- Description: Mod de doblaje al español latino para Hollow Knight
- Dependencies
  + Core.FsmUtil
  + FrogCore
  + HKMirror
  + SFCore
  + Satchel
- Tags
  + Gameplay

### mahoraga-wheel

- Description: Hollow Knight mod that replaces the Absolute Radiance halo with mahogara&#x27;s wheel
- Dependencies
  + ModCommon
  + Satchel
- Tags
  + Cosmetic

- Version: 1.0.0.0 -> 1.5.0.0
