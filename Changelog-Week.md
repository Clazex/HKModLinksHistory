# Changelog


## New mods

### Champion&#x27;s Shell

- Description: Adds Champion&#x27;s Shell, a 1-notch charm found in Dirtmouth that shows enemy health bars. Upgrade it at the Nailsmith with geo and relics to deal bonus nail damage to nearly dead enemies.
- Dependencies
  + SFCore
- Tags
  + Charm
  + LLM-Assisted

### GeoShare

- Description: Allows players to transfer Geo in HKMP lobbies using chat commands.
- Dependencies
  + HKMP
- Tags
  + Gameplay

### QoL.Lite

- Description: A range of quality of life changes that are valid for Team Hitless no hit runs.
- Dependencies
  + Vasi
- Tags
  + Utility
