## New mods

### ConfigurableMaskDamage

- Description: Changes the amount of damage dealt to the knight
- Dependencies
  + Satchel
- Tags
  + Gameplay

### ExaltationExpanded

- Description: A fan-made supplement to the Exaltation mod created by Xhuis (and ported/updated by Théodore).

  + HKMirror

  + SFCore
- Tags
  + Gameplay

- Tags
