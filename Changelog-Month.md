# Changelog


## New mods

### Afterimage Plus

- Description: A mod that gives customizable afterimages to the Knight and enemies.
- Tags
  + Cosmetic

### Biblically Accurate Lasers

- Description: Adds some configurable lasers to the Radiance and Absolute Radiance fights.
- Tags
  + Boss

### Hollow Knight Achievement Manager

- Description: Allows to manage Hollow Knight achievements, both vanilla and modded. Also syncs them with the online store of choice (GOG, Steam, XBox).
- Dependencies
  + SFCore
  + Satchel
- Tags
  + Utility

### RemoveLaggyObjects

- Description: Removes various objects from scenes where they can cause major lag.
- Tags
  + Cosmetic
  + Gameplay

### Seer

- Description: Seer Modded Boss
- Dependencies
  + More Godhome Space
  + SFCore
  + WeaverCore

### SkiploverSpoilerLog

- Description: Creates a Skiplover Spoiler Log in the Rando Logs directory showing what would be reachable with All skips enabled.
- Dependencies
  + CondensedSpoilerLogger
