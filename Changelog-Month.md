# Changelog


## New mods

### BenchDeploy

- Description: Deploy Multi Bench use controller/keyboard
- Dependencies
  + Benchwarp
  + MagicUI

### BossSync

- Description: An extension mod for ItemSync that allows for the synchronization of bosses!
- Dependencies
  + ItemSync
  + MenuChanger
  + Randomizer 4

### Elderbugnest

- Description: Replaces a bunch of NPCs with the sweet old friend
- Dependencies
  + Satchel

### SaferWhitePalace

- Description: Allows you to remove the dangers of White Palace
- Dependencies
  + Satchel

### UnrestrictedSteelSoul

- Description: A Hollow Knight mod that enables permadeath in dream/godhome zones when playing in steel soul mode.
- Tags
  + Gameplay
